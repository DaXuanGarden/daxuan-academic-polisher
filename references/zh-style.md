# Chinese academic style

## Default register

Write like a careful Chinese academic author: concise, direct, and readable to a colleague
outside the narrow subfield. Preserve the author's person and voice (`本研究`, `我们`,
`笔者`, or an impersonal construction) unless the user asks for a deliberate change.
Use concrete subjects and verbs, given-to-new information flow, varied sentence length, and
a claim-first paragraph.

## Review prompts

Treat these as contextual prompts, never as an automatic deletion dictionary. Remove a frame
only when it adds no supported meaning; keep it when it is a fixed technical term or carries
a real relation.

| Pattern to inspect | Plainer move when the source supports it |
| --- | --- |
| “随着……发展”“在……背景下”“众所周知” | open with the actual problem or finding |
| “值得注意的是”“需要指出的是”“综上所述” | delete, or state the new conclusion directly |
| “进行了……的研究/分析”“起到了……的作用” | use a concrete verb: “研究/分析了……”“是/用于……” |
| “具有重要意义”“提供新的思路”“奠定坚实基础” | name the supported result, gap, or next test |
| “进一步、有效地、极大地、在一定程度上” | keep only when it changes the evidence or scope |
| “系统、全面、深入、显著、首次” | retain only with the field-specific or statistical support |

Reduce policy-style four-character strings, forced triads, mechanical “首先/其次/最后”,
long enumeration, repeated sentence openings, paired em-dash asides, and paragraph-final
restatement. Do not add bullet points, headings, bold, or a new paragraph structure to
ordinary prose.

## Register choices

- **Chinese journal prose:** use an objective, compact reporting style; keep the requested
  abstract and keyword format and distinguish observation from interpretation.
- **NSFC text:** make the phenomenon or need, evidence gap, hypothesis, key scientific
  question, objectives, feasibility, and testable innovation visible. Replace abstract
  “意义/前景” claims with what is new, compared with what, and what can be tested. Preserve
  required headings such as “立项依据” and “拟解决的关键科学问题”.
- **Methods:** retain the source's objective or passive convention; do not fill in missing
  protocol details. **Results:** place the finding and quantitative support early.
  **Discussion:** separate result, interpretation, limitation, and implication.

## Integrity warning

Do not translate an English draft into Chinese merely because the user writes in Chinese. When
Chinese output is explicitly requested, keep scientific identifiers and citations intact and
mark uncertain standard Chinese equivalents with `[待核实: ...]`.
